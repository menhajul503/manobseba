# Manobseba Fund Management UI

A React + Tailwind CSS starter UI for a village-based charity dashboard. The design supports a clean NGO-style admin and user portal with a soft green, white, and light blue palette.

## What's included

- Login page with centered card design
- Super Admin dashboard with fund metrics, activity list, and chart section
- User dashboard with contribution summary, payment history, notices, and profile card
- Member management page with add form, search, and member table
- Donation page with add donation form and history table
- Distribution page with create event form and event cards
- Notice page for admin publish and user view list
- Responsive sidebar and top navbar layout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Uses React Router for page navigation
- Tailwind CSS for modern utility styling
- Ready to extend with real API data and authentication
